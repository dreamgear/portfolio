The AI that I was using in Google Antigravity suggested that I start building on Github instead of on the Linux host I was using.  Sounds complicated, I thought, but I was impressed with the simplicity of the solution the AI gave me.  It's almost entirely contained within one 80 line deploy.yml file.  It refers to secrets defined in the repo settings.  That's the only part of this that's not world-readable.  I don't have any problem with that, since the point of this site is to get people to look at the code I've created (I and my AI minions).

I may do a blow-by-blow of the deploy.yml file later, after I learn some more about github actions.  But here's the basics of what it does:

First, it defines environment variables for GHCR, the github container registry.  Then it defines a job called build-and-deploy with the following steps:  

- Checkout (check the code out)
- Setup Node.js
- Install dependencies
- Generate static site
- Stage output
- Log in to GHCR
- Extract Docker metadata
- Build and push Docker image
- Deploy to server via SSH.

These steps use predefined actions from the GitHub Marketplace.

The Github Actions facility, with GitHub Container Registry and  Docker Compose on the host, can build impressive sites with just two files, the docker-compose file and the deploy file.
